==================================================
🚀 HOW TO USE
==================================================

1. Drag the desired track folder (e.g., /Morning_Mist/) into your project.
2. Inside, you'll find the Full mix and a /Stems/ folder.
3. Assign the Full track to an Audio Source – enable "Loop" for seamless playback.
4. Use the stems for dynamic mixing (add/remove layers in-game).

==================================================
🎼 VERSIONS EXPLANATION
==================================================

- FULL: Complete track with melody and full arrangement.
- STEMS: Individual instrument groups (strings, woodwinds, brass, harp/celesta/glockenspiel, etc.) – continuous (full track length) for easy alignment.
